# Atomos research and evidence rules

Strict single-day reporting for Atomos monitors, recorders, wireless sync, audio and production workflows.

- **Research date:** 19:00 Pakistan time, `0 14 * * *` UTC; report covers the current calendar day as partial-day snapshot.
- **Brand:** direct Atomos, AtomOS or ATOMOSphere mention required in original source text.
- **Products:** Ninja TX/TX GO/RAW/Ultra, Shogun/Ultra/AV-19, Shinobi II/7 RX/GO, Sumo, UltraSync, TX-RX, StudioSonic, A-Eye PTZ, ATOMOSphere and supported accessories.
- **Sources:** public Facebook, Instagram, X, LinkedIn, Reddit indexed URLs, YouTube API if configured, camera forums, original bylined editorial articles, Atomos News Feed, retailers.
- **Evidence:** dated exact original URL, author/publisher, excerpt, sentiment, source photo attribution, visible post engagement and original comments.
- **Do not infer** private analytics, all-platform coverage, or unverified dates. Retail price observations are not social sentiment.
- **Costs:** GPT-4.1-mini optional bounded platform-sweep requests consume API credits; each calendar date has cache/attempt guards.
- **Website:** independent dark high-contrast design patterned on atomos.com; monthly calendar with newest report shortcut and PDF viewer.

GitHub Actions Secrets must be configured in the NEW repository: `OPENAI_API_KEY`, optionally `YOUTUBE_API_KEY`.

No prior Angelbird source data or PDFs are intentionally included in this clone.
